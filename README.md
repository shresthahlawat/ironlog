# IRONLOG

A gym tracker for a 6-day Push / Pull / Legs split, built with React and Vite.

**Live demo: [ironlog-six-hazel.vercel.app](https://ironlog-six-hazel.vercel.app/)**

## Features
- Six training days (Push A/B, Pull A/B, Legs A/B) plus a rest day
- Log the weight for each set and tick it off when done
- Easier-option swap for every exercise
- Rest timer between sets and exercises, with vibration alert
- Progress tab: line charts of your heaviest set per lift, with personal records
- Record tab with every past session
- Workouts are saved in your browser, so they stay after a refresh
- Dark, mobile-friendly design

## Run it locally
```bash
npm install
npm run dev
```
Then open the address shown in the terminal (usually http://localhost:5173).
